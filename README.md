# ishtaria-web

<img src="https://git.vitexsoftware.com/Ishtaria/ishtaria-client/raw/branch/main/assets/branding/emblem.png" alt="Ishtaria" width="96">

Public portal of Ishtaria: introduction of the game and download instructions for its
Debian packages. English (default) and Czech. Static HTML, generated by `build.py`
(Python standard library only), shipped as the `ishtaria-web` Debian package.

**Status:** two pages (home, download) in two languages, with a hero image and two in-game screenshots (`static/screenshot-*.jpg`, captured with the real client; CC0 Kenney and Quaternius assets).
Any imagery must come from the approved sources listed in the workspace `AGENTS.md`.

## Layout

| Path | Purpose |
| --- | --- |
| `site.json` | Repository URL, package list, which packages are for playing/hosting, and the client release files offered for direct download |
| `i18n/en.json`, `i18n/cs.json` | All page text; both files must have the same keys |
| `build.py` | Generates `build/html/` (English at `/`, Czech at `/cs/`) |
| `static/style.css` | Styling (light and dark via `prefers-color-scheme`) |
| `tests/check.py` | i18n key parity, every package described, no broken local links |
| `debian/` | Packaging, example nginx site, Jenkinsfile |

The page `play.html` ("Play in your browser") posts a server address to `/play/`, where nginx serves the files of the package
`ishtaria-client-web` (the browser build of the client, see its README); `debian/nginx-site` (nginx) and `debian/apache2-site` (Apache2, the live site
ishtaria.vitexsoftware.com) have that location and, commented out,
a `/server/` proxy for a game server on the same origin (`/play/?server=/server`: no CORS, no mixed content). Without the
package installed `/play/` answers 404.

Adding a package to the download table: add it to `packages` in `site.json` and a `pkg_<name>`
text to **both** language files, then `make test`.

## Development

```sh
make test     # build into a temp dir and check
make html     # build/html
make serve    # http://127.0.0.1:8080
```

## Installation

```sh
sudo wget -O /usr/share/keyrings/vitexsoftware.gpg https://repo.vitexsoftware.com/KEY.gpg
echo "deb [signed-by=/usr/share/keyrings/vitexsoftware.gpg] https://repo.vitexsoftware.com $(lsb_release -sc) main games" | sudo tee /etc/apt/sources.list.d/vitexsoftware.list
sudo apt update
sudo apt install ishtaria-web
```

The site lands in `/usr/share/ishtaria-web/html`. Example sites are installed for nginx
(`/etc/nginx/sites-available/ishtaria-web`) and for Apache2
(`/etc/apache2/sites-available/ishtaria-web.conf`; `a2enmod headers mime`, then `a2ensite ishtaria-web`),
conffiles that are not enabled automatically. Enable one and put TLS in front before exposing it. It also serves `/doc/ishtaria-doc/` from the
`ishtaria-doc` package when installed; the portal's "Documentation" link points there.

## Package build

```sh
dpkg-buildpackage -us -uc -b
```

CI: `.github/workflows/ci.yml` and `debian/Jenkinsfile`.
